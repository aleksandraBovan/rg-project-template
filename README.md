# 01 - Postavljanje projekta

Impltementirana petlja renderovanja

Zatvaranje prozora na Esc

Promena boje pozadine pritiskom na tastaturu (r|g|b)

Promena veličine prozora na Ctrl + (←|↑|→|↓)

Levim klikom miša prozor dobija nasumičnu boju

Left Click + Shift => (r, g, b) = (x, y, 0) gde su (x, y) koordinate miša
